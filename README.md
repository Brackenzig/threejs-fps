RELAY / NINE — a 3v3 tactical FPS (Counter-Strike-style) in the browser: two teams, rounds won by elimination or planting a relay charge, buy phase between rounds, bots with site anchors and reaction delays. Built for the [make.fun bounty "Make the best three.js tactical FPS"](https://make.fun/bounty/threejs-fps-02) (threejs-fps-02).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to move, mouse to aim, R reload, B buy, G grenade, E plant.
